# PDV PRO — instaladores e atualizações

Este repositório guarda **apenas os instaladores** do PDV PRO (programa de frente de caixa, estoque, clientes e fiado
para o pequeno varejo, em Windows) e os arquivos que o próprio programa usa para se atualizar sozinho. Não há
código-fonte aqui.

- **Baixar a versão mais recente:** [Releases › Latest](https://github.com/wbaldicera/pdv-pro-atualizacoes/releases/latest)
- **Requisitos:** Windows 10 ou 11 (64 bits). Funciona sem internet; a internet só serve para atualizar.
- **Licença:** o programa funciona 30 dias de teste, com tudo liberado; depois pede uma chave de licença, que vale para um
  computador.

Os arquivos de cada versão (`PDV-PRO-Setup-<versão>.exe`, `latest.yml` e `.blockmap`) são lidos pelos programas já
instalados para achar a atualização. Por isso, não apague nem renomeie arquivos de uma versão publicada.
